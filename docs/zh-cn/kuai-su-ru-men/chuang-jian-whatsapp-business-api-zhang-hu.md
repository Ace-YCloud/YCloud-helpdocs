# 创建WhatsApp Business API账户

## 开始前需要准备的资料

{% hint style="info" %}
请注意：如果您已经有了自己的BM账号的话，也可以在嵌入式注册的时候使用您现有的BM账号进行注册。
{% endhint %}

* 一个Facebook账号
* 电话号码
  * 该电话号码必须能够接收语音呼叫或短信
  * 该号码之前没有注册过WhatsApp App或者商业账户

## 步骤1: 创建WhatsApp Business API账号

{% hint style="info" %}
点击查看[超详细教程](../whatsapp-accounts-zhang-hao-guan-li/chuang-jian-whatsapp-api-zhang-hao/tong-guo-qian-ru-shi-zhu-ce-chuang-jian-waba.md)
{% endhint %}

* 访问YCloud后台，[点击访问](https://www.ycloud.com/console/?redirect=/edit/getting-started#/app/dashboard/getStarted)&#x20;
* 点击下图按钮，开始嵌入式注册流程

<figure><img src="../.gitbook/assets/image (360).png" alt=""><figcaption></figcaption></figure>

* 创建成功后，可以在WhatsApp Account检查账户，[前往👉](https://www.ycloud.com/console/?redirect=/edit/getting-started#/app/dashboard/account)



## 步骤2: 完成企业认证

{% hint style="warning" %}
为什么要进行企业认证：

* 未经认证的BM帐号：最多只能关联2个号码，且每日的对话上限为250个
* 经过认证的BM账号：可最多关联20个号码，且每日的对话上限可成长
{% endhint %}

{% hint style="info" %}
点击查看[超详细教程](https://ycloud-team.gitbook.io/help-center/whatsapp-ji-chu/qi-ye-ren-zheng)
{% endhint %}

### 1. 准备材料

请准备以下材料，并**确保所有材料真实可靠**：

{% hint style="danger" %}
请注意：请确保您的公司官网底部包含了您对应的企业营业执照的公司信息，且二者需要完全一致
{% endhint %}

* 企业的基本信息：名称，地址，电话号码，官网&#x20;
* 营业执照/注册登记证

### 2. 发起BM认证

确保您是BM账户的管理员，然后[前往BM后台安全中心](https://business.facebook.com/settings/security)发起验证：

<figure><img src="../.gitbook/assets/image (389).png" alt=""><figcaption><p>BM账号安全中心页面</p></figcaption></figure>



### 3. 等待验证结果

通常需要 1-2 个工作日，您将收到电子邮件通知。
