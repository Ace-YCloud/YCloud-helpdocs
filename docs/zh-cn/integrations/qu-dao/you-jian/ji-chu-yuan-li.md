# 基础原理

电子邮件发送的主要目的是提高客户参与度和保留率，或提高营销活动的投资回报率。如果由于任何原因未发送电子邮件，则电子邮件的内容将没有机会被阅读、点击或为您的业务带来任何结果。\
本节将解释 Email 的工作原理以及帮助您做出最佳决策的相关基础。



## 送达能力

电子邮件送达率，是衡量互联网服务提供商 (ISP) 成功收到的电子邮件数量的指标（无论这些电子邮件是发送至收件箱还是垃圾邮件文件夹中）。它只是指未退回的电子邮件的百分比。<br>

当您点击“发送”时，您的电子邮件会先经过各种过滤器，然后才会发送到收件人。该过程中的关键步骤之一是避免被标记为垃圾邮件或被转移到垃圾邮件文件夹中。

\
Gmail、Outlook 和 Yahoo Mail 等主要 ISP 采用先进的垃圾邮件过滤方法来保护其用户和邮件服务免遭利用。这些垃圾邮件过滤器充当第一道防线，分析收到的电子邮件并允许好的电子邮件进入收件箱，同时将坏的电子邮件过滤到垃圾邮件或完全拒绝它们。<br>

您的 I**P 地址、信誉和域名**对于确保您的电子邮件进入客户的收件箱都起着至关重要的作用。

## 域名验证

为了确保电子邮件的送达率和收件箱率，对发送的域名进行身份验证非常重要。这样，电子邮件提供商将允许 YCloud 使用您的域名发送电子邮件。这不仅提高了电子邮件送达的机会，还降低了电子邮件被收件人标记为垃圾邮件的可能性。

首先，您只需在 YCloud 平台上配置您的发送域名并获取验证所需的 DNS 记录。获得记录后，您可以通过将域名系统 (DNS) 记录配置到您的域名管理上即可。

通过验证的域名，您可以清楚地向收件人表明该电子邮件来自谁，从而建立信任和可信度。因此，强烈建议您完成此过程，以确保电子邮件营销活动取得成功。

## IP地址

在发送电子邮件活动时，IP 有两种选择：共享和专用。

对于小规模电子邮件活动来说，共享 IP 地址是一种经济高效的解决方案，因为它在多个域之间共享。但是，由于您无法控制发件人的声誉，因此请务必记住，即使该 IP 地址上有一个不良发件人，也可能会导致使用该地址的其他人出现送达问题。

另一方面，专用 IP 地址专门用于您的活动，提供与 ISP 的直接连接并更快地交付给收件人。如果您每周发送大量电子邮件，专用 IP 是保护您声誉的宝贵投资。

YCloud默认使用共享IP，如需分配专用 IP，可以从 YCloud 购买，并按月定期收取专用 IP 费用。

## 信誉

发送电子邮件是沟通的重要组成部分，但请务必记住，发送的每封电子邮件可能影响您信誉。互联网服务提供商 (ISP) 收集有关您的发送行为的数据，包括您的域名（电子邮件地址中“@”符号后面的部分）和 IP 地址（您的发送活动的唯一标识符）。

为了确保您的电子邮件成功送达，保持良好的 IP 和域名信誉非常重要。接收服务器在评估信誉时会考虑多个因素，包括其他收件人对来自同一 IP 和域的邮件的反应（例如，是否被标记为垃圾邮件），以及来自同一 IP 和域的先前邮件的放置位置。

为了培养良好的信誉，建议使用自己的域名、进行 IP 预热发送、仅发送给需要该电子邮件的人，以及高质量的内容。通过采取这些步骤，您可以确保您的电子邮件发送到收件人的收件箱，并保持高信誉。

信誉度扣分项有以下几个：服务器不可达；地址格式错误；地址不存在；垃圾邮件；垃圾举报。

&#x20;

## 订阅者偏好和取消订阅

为了与订阅者建立信任和信誉，让他们控制自己的通信偏好非常重要。您可以通过允许他们选择他们喜欢的联系渠道（短信、应用程序push、电子邮件等）、他们感兴趣的主题、他们喜欢的消息类型以及他们接收通信的频率来实现这一目标。

除了建立信任之外，还必须遵守法律并确保您的电子邮件送达收件人。为了实现这一目标，在您的电子邮件营销活动中包含取消订阅链接非常重要。这使您的订阅者可以轻松选择不再接收未来的电子邮件，这有助于防止您的电子邮件被标记为垃圾邮件。

## &#x20;合法合规

具有功能性取消订阅链接的有效偏好中心不仅是良好实践，而且也是遵守 CAN-SPAM 法案的强制性要求。该法案要求所有取消订阅均在十个工作日内有效、有效且得到兑现。<br>

为了遵守法律，您必须获得用户的明确选择加入许可。确认的选择加入列表从一开始就更具吸引力，并将有效帮助您建立发件人信誉。通过仅向同意接收电子邮件的人发送电子邮件，您可以避免被收件人标记为垃圾邮件。如果太多收件人将您的电子邮件标记为垃圾邮件，ISP 可能会认为您正在向发件人列表中的每个人发送垃圾邮件，甚至包括那些选择接收您的电子邮件的人。\
通过遵循电子邮件营销的最佳实践并遵守法律，您可以确保您的电子邮件受到受众的好评，并且发件人的声誉保持良好。

电子邮件选择加入法律：

* [美国反垃圾邮件法](https://www.ftc.gov/business-guidance/resources/can-spam-act-compliance-guide-business)
* [澳大利亚和加拿大的 CASL](https://ised-isde.canada.ca/site/canada-anti-spam-legislation/en)
* [欧盟 GDPR](https://www.gdpreu.org/compliance/email-marketing/)
