# 预热发送

新的域或 IP 地址可能会被 ISP 视为可疑，直到它们建立了良好的发件人信誉。为了提高电子邮件送达率，重要的是通过增加发送量来逐步预热 IP/域/信誉，同时确保电子邮件正常送达。

预热是一个需要时间的过程，需要仔细考虑收件人、频率和内容。在预热过程中，监控电子邮件返回并根据需要调整发送策略以确保电子邮件正常送达非常重要。以下是需要考虑的一些关键因素：

* 目标收件人：仅向那些选择加入的人发送电子邮件，尤其是那些最不可能抱怨或退回的人。
* 电子邮件频率：将电子邮件发送频率控制在适当的水平，避免过快发送过多电子邮件。
* 电子邮件质量：确保您的电子邮件具有高质量，并避免发送非法或垃圾邮件。

通过遵循这些准则，您可以成功地提升您的 IP/域声誉并提高您的电子邮件送达率。

## 预热建议

我们建议您遵循简单的 14 天计划。每天的发送量如下表所示。

| 天      | 每日交易量   |
| ------ | ------- |
| 第1天    | 200     |
| 第2天    | 500     |
| 第3天    | 1000    |
| 第 4 天  | 2000    |
| 第5天    | 5000    |
| 第6天    | 10,000  |
| 第 7 天  | 14,000  |
| 第 8 天  | 20,000  |
| 第 9 天  | 25,000  |
| 第 10 天 | 35,000  |
| 第 11 天 | 50,000  |
| 第 12 天 | 80,000  |
| 第 13 天 | 130,000 |
| 第 14 天 | 20万     |

如果邮件送达率低于85%，建议恢复到前一天的发送速度，以保证更高的成功率。
