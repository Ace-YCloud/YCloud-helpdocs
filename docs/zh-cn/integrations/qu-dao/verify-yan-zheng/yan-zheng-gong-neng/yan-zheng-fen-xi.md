# 验证分析

YCloud verify提供了验证请求-发送-成功的完整数据循环，每天自动向企业发送验证报告。每条验证日志清晰可追溯。

{% hint style="info" %}
🚧注意：如果您使用[自定义验证码](zi-ding-yi-otp.md)，我们可能无法向您显示验证的成功率。因此，我们建议，无论您是否使用自定义验证码，请通过验证码API提供反馈，让我们知道用户是否已验证码。这还可以帮助我们监控全球通信渠道，以确保最高的消息传递率。
{% endhint %}
