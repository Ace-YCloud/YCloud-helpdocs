# Inbox介绍

## 概述

YCloud Inbox是基于WhatsApp的实时聊天工具，客服及销售团队可以通过它与客户建立更紧密的联系，轻松处理查询、解决问题和收集反馈！Inbox有详细的数据分析报告，帮助您制定数据驱动的管理及决策。
