# 优惠券Code模板

优惠券代码模板归属于营销模板，是显示单个复制代码按钮的营销模板。点击后，代码将复制到客户的剪贴板。

<figure><img src="../../.gitbook/assets/image (549).png" alt="" width="192"><figcaption></figcaption></figure>

### 限制 <a href="#limitations" id="limitations"></a>

* WhatsApp web客户端目前不支持优惠券代码模板。
* 代码限制为 15 个字符。
* 按钮文字无法自定义。
* 模板仅限于一个复制代码按钮。
