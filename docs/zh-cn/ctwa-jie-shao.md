# CTWA介绍

### 一、什么是CTWA广告？

#### 1.1 CTWA的定义

CTWA，全称"Click to WhatsApp Ads"（点击跳转到WhatsApp的广告），是一种可以让用户直接从广告跳转到WhatsApp与您的企业开启对话的广告形式。

**简单来说：**

* 用户在Facebook、Instagram、TikTok或Google等平台看到您的广告
* 点击广告上的"发送消息"或"在WhatsApp上聊天"按钮
* 自动打开WhatsApp对话窗口
* 立即与您的企业开始沟通



#### 1.2 CTWA与传统广告的对比

{% hint style="info" %}
CTWA的核心优势：

* ✅ **缩短转化路径**：取消落地页，将潜在客户从广告平台直接引流至WhatsApp私域，一键直达对话
* ✅ **即时沟通 + 自动获取联系方式**：利用WhatsApp的即时性快速响应客户，同时用户一旦发送消息，企业立即获取其WhatsApp号码（手机号），便于后续持续沟通和营销转化
* ✅ **精细化运营**：收集高质量的对话数据和转化事件，实时回传给广告平台（Meta、TikTok），持续优化广告投放效果
* ✅ **降低成本**：从CTWA广告入口开始的WhatsApp对话，在对话开始后的72小时内不收取WhatsApp对话费用
{% endhint %}
