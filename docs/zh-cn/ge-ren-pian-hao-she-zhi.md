# 个人偏好设置

个人偏好设置涵盖个人资料、安全、通知等设置，可让您依自身需求定制，获得更舒适便捷的体验。

## 个人资料

在“Your preference > [Profile](https://www.ycloud.com/console/#/app/userSettings/myProfile)”中，您可以设置您的个人信息，包括您的姓名、头像、邮箱及手机号码，支持修改密码。

<figure><img src="../.gitbook/assets/image (561).png" alt=""><figcaption></figcaption></figure>

### 头像

您可以在个人偏好设置中选择或上传自己喜欢的头像，在后续转接会话等操作中便于区分。鼠标悬浮到头像上可进行大图预览，和删除操作。建议头像尺寸640 x 640 px, 小于5MB。

{% hint style="info" %}
操作完成后请点击区域底部的保存按钮，更改才会生效
{% endhint %}

### 名字

在此设置您的名字，以便在系统中清晰准确地标识您的身份。

### 邮箱

邮箱不支持修改，仅展示

### 手机号码

填写您的手机号码，方便进行必要的2fa验证，保障账户安全。可点击修改按钮，进行手机号修改。

{% hint style="info" %}
修改手机号需要先验证之前手机号.请在弹窗中点击“Get Code”，验证手机号。　
{% endhint %}

### 切换语言

支持切换您想要选择的系统语言

<figure><img src="../.gitbook/assets/image (197).png" alt=""><figcaption></figcaption></figure>

### 修改密码

通过此功能更新密码，增强账户的安全性。



## 安全

启用双重身份验证来保护您的账户。我们会通过短信或电子邮件向您注册的联系方式发送一次性密码（OTP）

设置路径 点击左下角头像 Edit >Your preference > [Security](https://www.ycloud.com/console/#/app/userSettings/security)

* 修改开关需要通过短信或者邮箱认证。
* 2fa开启，则进入账号时需要进行邮箱或短信验证。

<figure><img src="../.gitbook/assets/image (562).png" alt=""><figcaption></figcaption></figure>

## 通知

设置inbox的通知触发的场景：Account > [Notifications](https://www.ycloud.com/console/#/app/userSettings/notification)

* 设置声音提示触发时机
* 设置浏览器弹出提示触发时机（需开启浏览器提示权限）

<figure><img src="../.gitbook/assets/image (564).png" alt=""><figcaption></figcaption></figure>

## 个人快捷回复

每个用户可查看公司已预设的快捷回复供参考，也可以根据自己的需要设置个人快捷回复。

#### **查看公司快捷回复**

点击【Check Preset】按钮即可在右侧抽屉查看管理员已预设的快捷回复，支持通过短码或者内容对具体快捷回复进行搜索查询。

<figure><img src="../.gitbook/assets/My_Photor_1734071526298.jpg" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/My_Photor_1734073468514.jpg" alt=""><figcaption></figcaption></figure>

#### 设置个人快捷回复

通过点击新增快捷回复按钮可以新增个人快捷回复，根据具体需要输入短码和快捷回复内容，支持添加表情以及附件等内容。同时支持对已存在的个人回复进行搜索筛选以及编辑、删除操作。

<figure><img src="../.gitbook/assets/My_Photor_1734075731624.jpg" alt=""><figcaption></figcaption></figure>

#### 使用公司/个人快捷回复

<figure><img src="../.gitbook/assets/My_Photor_1734075942971.jpg" alt=""><figcaption></figcaption></figure>

您可以在Inbox对话框中输入“/”以唤起快捷回复窗口，并通过输入对应快捷回复的短码进行搜索需要的快捷回复，在右侧分栏窗口对快捷回复进行预览，确认这是您需要的快捷回复后按下回车键输入选中的快捷回复。在列表中公司预设的的快捷回复将带有标签来方便您进行区分。

## 欢迎消息

设置您独特的欢迎消息作为欢迎语，带给您的客户良好的第一印象。满足以下条件时将会触发您的欢迎消息：

* 会话为开启状态
* 会话由客户主动发起
* 会话转接给您

按照以下步骤设置使用欢迎消息：

1. 在个人设置菜单左侧选择欢迎消息，进入页面后您可以点击新增按钮新建您的欢迎消息。

<figure><img src="../.gitbook/assets/My_Photor_1734076615323.jpg" alt=""><figcaption></figcaption></figure>

2. 选择需要发送这条欢迎消息的whatsapp 商业号码

{% hint style="info" %}
注意：一个商业号码只能绑定一条欢迎消息。
{% endhint %}

3. 选择欢迎消息的类型，支持三种类型：

* 文本消息：纯文字类型消息。支持Emoji，加粗，斜体等样式。
* 富媒体消息。图片/视频/文件 + 文字类型的消息。
* 互动类消息。带按钮的互动消息，如快捷回复按钮、跳转按钮、列表按钮。

{% hint style="info" %}
注意：互动类消息中，如果您想使用列表按钮，Header务必设置为None或者纯文本Header。
{% endhint %}

<figure><img src="../.gitbook/assets/6.jpg" alt=""><figcaption></figcaption></figure>

4. 设置完成后打开开关即可开启欢迎消息。
5. 在开关**关闭**的情况下，您可以编辑或删除该条欢迎消息

<figure><img src="../.gitbook/assets/My_Photor_1734076769770.jpg" alt=""><figcaption></figcaption></figure>
