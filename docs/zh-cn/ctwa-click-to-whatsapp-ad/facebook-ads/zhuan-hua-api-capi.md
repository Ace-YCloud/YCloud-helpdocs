# 转化 API (CAPI)

那我们为什么要收集这些事件数据传递给Meta呢？主要有以下两点好处：

* **有助于改善定位：**&#x901A;过 CAPI 跟踪，您可以为广告活动提供更准确的信息。从而帮助广告平台理解和改善受众定位，以最大限度的提升广告的性能和效果。例如我们向它分享通过点击广告产生购买的用户事件，让广告活动以发生购买的用户画像来不断优化受众定位。
* **帮助您更好地了解受众：**&#x901A;过 CAPI 与 Meta 共享消息传递事件，您可以跟踪、衡量和了解这些事件在 Meta Ads Manager 中的执行情况，更深入地了解客户旅程。例如，您可以查看点击到 WhatsApp 的广告的购买次数和每次购买费用。这些信息可以帮助您做出更有效的营销决策

一旦将广告帐户连接到YCloud，我们将自动启用转化API，您将能够直接在事件管理器 [事件管理器](https://business.facebook.com/events_manager2/list/) 中访问它们。

#### **先决条件：**

1.投放的广告账户已连接到YCloud

2.至少有一个客户点击过CTWA并开启对话。
