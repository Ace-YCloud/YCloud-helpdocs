# 通话日志

## 查看权限

系统默认角色中，Admin、Manager 和 Operator 角色有权限访问 Calling logs 界面，您也可以通过自定义角色时勾选该权限来给特定角色赋予查看权限

## 使用通话日志

进入通话日志页面，管理员可查看列表内的通话日志相关信息，可以通过上方的筛选项对联系人进行搜索，或通过匹配其他条件进行具体通话定位

<figure><img src="../.gitbook/assets/My_Photor_1754465865853.jpg" alt=""><figcaption></figcaption></figure>

Hover第一列，点击出现的箭头符号，可选择跳转到联系人列表或该联系人的 calling 具体页面查看

<figure><img src="../.gitbook/assets/My_Photor_1754470193392.jpg" alt=""><figcaption></figcaption></figure>
