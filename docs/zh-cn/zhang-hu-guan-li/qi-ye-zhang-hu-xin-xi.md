# 企业账户信息

在“帐户设置”中，您可以提供有关您的帐户企业的基本信息，包括您的账号ID、公司名称、网站、税号、行业以及账单地址。

{% hint style="info" %}
仅角色为管理员时，账户设置可见且可编辑
{% endhint %}

## 企业相关信息

<figure><img src="../.gitbook/assets/image (641).png" alt=""><figcaption></figcaption></figure>

### 账号ID

这是分配给您的企业的唯一标识符。账号ID 帮助YCloud区分不同的企业。

### 公司名称

这是您的企业或品牌的名称，将显示在您的YCloud帐号上。如您登陆的用户同时属于不同账号，可以切换账号。路径：头像 > switch account 点击切换账号

### 税号

企业用于纳税申报和税务管理的唯一识别号码。

### 官方网站

您可以输入您企业的网站网址。

### 行业

企业所从事的主要业务领域或所属的经济分类。

## 账单地址

接收账单的邮寄地址，用于发送发票和费用明细。
