# Meta支持

## 对于特定的Meta相关主题，您必须直接联系Meta支持

包括Meta Business Manager以及Meta访问问题，您必须联系Meta Direct支持。

{% hint style="info" %}
直接支持是一种私人支持渠道，可将企业与 Facebook 的特定支持团队联系起来，以提供特定的商业产品和服务，包括但不限于 Facebook 商业合作伙伴、Facebook 平台和即时文章。并非所有用户都可以访问直接支持
{% endhint %}

{% hint style="info" %}
出于安全原因，我们不支持 Meta Business Manager 访问问题或恢复。如果您无法访问 Meta Business Manager 账户，则必须联系 Meta 支持以重新获得帐户访问权限。
{% endhint %}
