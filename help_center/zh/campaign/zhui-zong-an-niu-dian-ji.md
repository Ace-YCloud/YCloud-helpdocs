# 追踪按钮点击

{% hint style="info" %}
企业在申请通知和营销模板时，可以打开Visit Website按钮的点击追踪功能；该功能支持企业在完成Campaign后，在对应分析页面查看按钮的点击数据；能够帮助企业进行内部数据追踪和分析。
{% endhint %}
